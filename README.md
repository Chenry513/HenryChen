# HenryChen
HenryChen is a Jekyll-powered blog and documentation website, built with a custom theme and a wide range of features for content creation and publication. This project utilizes a Ruby-based tech stack, including Jekyll, HTML, and various dependencies for math formula rendering and JavaScript runtime.

## Features
* Customizable theme with support for math formulas and JavaScript runtime
* Advanced documentation and blog post features, including syntax highlighting and image support
* Automated deployment and building using GitHub Actions and Jekyll
* Support for multiple authors and social media integration
* Fully responsive design with support for various screen sizes and devices

## Installation
To get started with this project, you'll need to have the following dependencies installed:
* Ruby (version 2.7 or higher)
* Jekyll (version 4.3 or higher)
* Bundler (for managing dependencies)

You can install the required dependencies by running the following commands:
```bash
gem install jekyll
gem install bundler
```
Once you have the dependencies installed, clone the repository and navigate to the project directory:
```bash
git clone https://github.com/your-username/HenryChen.git
cd HenryChen
```
Install the required gems by running:
```bash
bundle install
```
## Usage
To build and serve the website, run the following command:
```bash
bundle exec jekyll serve
```
This will start the development server, and you can access the website by navigating to `http://localhost:4000` in your web browser.
